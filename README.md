# Khalil's Premium Portfolio

Create a premium personal portfolio website using Next.js, TypeScript, and Tailwind CSS.

Goal:

Build a high-end developer portfolio landing page that looks professional enough to share with clients, especially Upwork clients. The design should feel modern, premium, clean, and conversion-focused.

Tech Stack:

- Next.js (latest version)

- TypeScript

- Tailwind CSS

- Framer Motion for smooth animations

- Lucide React icons

- Fully responsive (desktop, tablet, mobile)

Design Direction:

Create a premium SaaS-style portfolio website.

Use:

- Clean white/dark modern theme

- Smooth gradients

- Glassmorphism cards

- Soft shadows

- Premium hover animations

- Micro interactions

- Smooth scrolling

- Elegant typography
